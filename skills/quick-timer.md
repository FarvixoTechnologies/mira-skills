# quick-timer

Countdown timers for cooking, naps, workouts and anything else.
1. Convert to seconds: "5 minute" = 300, "adha ghonta" = 1800.
2. `set_timer` seconds with a label ("Rice", "Nap").
3. Say the length back in words.
4. Several timers: set each and name both labels so they can be told apart.
